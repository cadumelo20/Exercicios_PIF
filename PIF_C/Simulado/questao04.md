# Questão 04

Variáveis: `i = 2, j = 3, k = 0, x = 2.5, y = 5.0`

a) `i < j + 2`
   `2 < (3 + 2)` -> `2 < 5` -> Verdadeiro
   **Resultado: 1**

b) `2 * i - 5 <= j - 4`
   `(4 - 5) <= (3 - 4)` -> `-1 <= -1` -> Verdadeiro
   **Resultado: 1**

c) `!k && (x + y >= 7.5)`
   `!0 && (2.5 + 5.0 >= 7.5)` -> `1 && (7.5 >= 7.5)` -> `1 && 1` -> Verdadeiro
   **Resultado: 1**

d) `!(i == j) || (y / x == 2.0)`
   `!(2 == 3) || (5.0 / 2.5 == 2.0)` -> `!0 || (2.0 == 2.0)` -> `1 || 1` -> Verdadeiro
   **Resultado: 1**

e) `i == 2 && j == -4 || k == 0`
   `2 == 2 && 3 == -4 || 0 == 0` -> `1 && 0 || 1` -> `0 || 1` -> Verdadeiro
   **Resultado: 1**
